# Pomodoro Helper

Таймер помодоро для отслеживания времени занятий.

## Что умеет

- Отсчёт 25 минут работы, 5 минут перерыва.
- 4 круга, после четвёртого — длинный перерыв 15 минут.
- Звуковой сигнал в конце каждого отрезка.
- Запись сессии в CSV: дата старта, тема, длительность, статус (завершена или прервана).

## Как запустить

1. Открыть терминал в папке проекта.
2. Выполнить:

   ```
   python main.py
   ```

3. Ввести название задачи, когда программа спросит.
4. Таймер начнёт отсчёт.

Прервать работу можно через `Ctrl+C`.

## Куда пишутся данные

Данные о сессиях сохраняются в файл `sessions.csv` в папке проекта.

Колонки:

| Колонка | Что содержит |
|---|---|
| `name_session` | название задачи, введённое пользователем |
| `start_session` | дата и время старта сессии |
| `duration` | длительность в секундах |
| `is_completed` | `True`, если сессия завершена, `False` — если прервана |

Файл создаётся автоматически при первом запуске.
